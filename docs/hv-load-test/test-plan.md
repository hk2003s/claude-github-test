## 2. 試験目的

1. 定格範囲内で出力電圧・電流が仕様を満たすことの確認
2. 負荷変動・ライン変動時の安定度の確認
3. 保護機能 (OVP/OCP/アーク/インターロック) の動作確認
4. 連続運転時の熱的安定性の確認

## 5. 必要機材 (要選定)

| 区分 | 用途 | 選定の要点 |
|---|---|---|
| HV負荷 | 定格電力を連続消費 | 定格電圧・電力に十分な余裕、温度係数、電圧係数、放熱/冷却 |
| HV分圧器/プローブ | 電圧測定 | 定格電圧、分圧比確度、周波数帯域 |
| 電流計/シャント | 電流測定 | 接続位置はGND側 (低電位側) を推奨 |
| DMM | 静特性測定 | 入力インピーダンス、確度が被試験仕様の 1/4〜1/10 以下 |
| オシロスコープ | リップル・過渡 | 帯域、HV差動プローブ |
| 電力計 | 入力電力・効率 | 確度 |
| 温度ロガー | 熱的安定性 | 熱電対チャネル数 |
| 制御PC | 自動化・記録 | VISA/SCPI対応I/F |
| 安全機材 | 保護 | 4章・安全手順書参照 |

## 6. 校正・トレーサビリティ

- 使用する計測器の校正期限を試験前に確認し、記録する。
- 測定不確かさを見積もり、合否判定の余裕を確認する (計測器確度 ≦ 仕様確度の 1/4 を目安とする。※一般的な指針であり、社内規定があればそちらに従う)。

## 7. データ記録

- 試験ごとに、日時、周囲温度/湿度、使用機材 (校正期限)、設定値、測定値、判定を記録する。
- 記録様式は `data-sheet-template.csv` を使用する。
