# HV電源 負荷試験 安全手順書・実施手順書

> 状態: **テンプレート (DRAFT)**。高電圧は致命的になり得る。実施前に、所属組織の安全規定・有資格者の確認・
> 対象電源の取扱説明書を必ず優先すること。本書は一般的な指針であり、法令・規格への適合を保証しない。
> (適用規格・社内規定の要否は「不明」。要確認: 例として IEC 61010-1 等、国内の電気安全関連規則)

## 1. 安全要件

1. **作業者**: HV取扱いの教育を受けた者。**単独作業は禁止** (監視者を1名以上置く)。
2. **試験エリア**: 区画 (柵/インターロック付き扉) を設け、「高電圧試験中」の表示と警告灯を設置する。
3. **接地**: 共通の保安接地に確実に接続。接地線は試験中に外れない構造にする。
4. **放電**: 出力遮断後も蓄積電荷が残る。**放電確認 (放電棒/ブリーダ抵抗) が済むまで触れない。**
5. **非常停止**: 作業者の手の届く位置に非常停止を設置し、動作を毎回試験前に確認する。
6. **インターロック**: 扉開放で出力遮断すること。バイパス禁止。
7. **配線**: HV定格のケーブル/コネクタ、十分な絶縁距離、露出導体なし。
8. **負荷**: 発熱・破損に備え、耐圧と電力に余裕を持たせ、飛散/火災対策をする。
9. **保護具**: 絶縁手袋 (定格電圧に適合)、保護メガネ。ペースメーカー等の使用者は立入禁止。
10. **通信制御**: 制御PCは、通信断時に出力が安全側 (遮断) になる構成にする。

## 2. 試験前チェックリスト

- [ ] 作業者・監視者の確認、作業記録の開始
- [ ] 区画・警告灯・非常停止・インターロックの動作確認
- [ ] 接地の導通確認
- [ ] 計測器の校正期限確認
- [ ] 配線を図面と照合 (電源OFF・放電済みの状態で)
- [ ] 電源の保護設定値 (OVP/OCP) を初期の低い値に設定
- [ ] 出力電圧設定が 0 V であることを確認

## 3. 実施手順 (共通)

1. 電源OFFの状態で配線し、`test-plan.md` 4章の構成と照合する。
2. 区画を閉じ、インターロックを有効化する。
3. 入力電源を投入し、出力OFFのまま自己診断が正常なことを確認する。
4. 負荷を最小の状態にして、出力を **低電圧から段階的** に上げる。各段階で電圧・電流・温度を確認する。
5. 各試験項目 (T01〜T10) を `test-plan.md` 3章の順に実施し、データシートに記録する。
6. 異常 (異音、異臭、放電、温度異常、保護動作の予期せぬ発生) があれば直ちに出力を遮断する。
7. 試験終了時: 出力電圧を 0 V にして出力OFF → 入力電源OFF → **放電確認** → 区画を開放する。
8. 結果を判定し、報告書にまとめる。

## 4. 異常時対応

| 事象 | 対応 |
|---|---|
| 放電/アーク | 出力OFF、非常停止、放電確認後に原因調査。再開前に責任者の承認を得る |
| 過熱 | 出力OFF、冷却待ち。再開前に負荷/配線を点検 |
| 感電/負傷 | 電源遮断を最優先 (救助者自身の二次被害に注意)、救急要請、責任者へ報告 |
| 通信断 | 出力が遮断されたことを確認し、原因を特定してから再開 |

## 5. 試験後

- 機材の状態確認 (焼損、変色、緩み)
- データのバックアップと報告書作成
- 逸脱・ヒヤリハットの記録
